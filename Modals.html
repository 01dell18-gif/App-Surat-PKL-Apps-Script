Riwayat versi & penambahan fitur kedinasan

Versi 2.4.0 Terbaru November 2026

Pembaruan arsitektur modular multi-page, template kedinasan baru, sistem informasi rilis interaktif, dan optimalisasi presisi margin cetak massal.

  • Arsitektur Modular Multi-Page (Scriptlet Pattern): Pemisahan kode menu menjadi file HTML mandiri per modul (Surat, Database, Template, Pengaturan) dengan Query Parameter Routing (?page=...) bebas blank putih.
  • Format Suket Monitoring & Nilai Otomatis: Menghilangkan blok Kepada Yth pada Suket Monitoring PKL agar langsung diawali judul Surat Tugas, serta standarisasi tanda '-' otomatis untuk NIP dan Pangkat/Golongan guru yang belum terisi di semua template surat.
  • Template Suket Monitoring PKL: Penambahan template resmi Surat Tugas Guru Pembimbing untuk monitoring berkala PKL siswa di lokasi DU/DI binaan.
  • Data Pangkat & Jabatan Pembimbing: Penambahan atribut Pangkat/Golongan dan Jabatan Guru Pembimbing pada database siswa, form edit, template surat, ekspor-impor Excel, dan cetak massal.
  • Perbaikan Header Tabel Database: Mengatasi space kosong dan kebocoran baris data pada sticky header tabel database siswa saat di-scroll.
  • Presisi Margin Cetak Massal: Mengatasi jarak berlebih pada lembar pertama dokumen cetak massal dan menyelaraskan pemisahan halaman cetak.
  • Proteksi Format Tabel: Memastikan tabel daftar siswa lampiran utuh tanpa terpotong baik saat cetak maupun ekspor dokumen Word.
Versi 2.3.0 November 2026
  • Unduh Massal ZIP: Kemampuan mengunduh seluruh arsip dokumen Word (.docx) secara massal dalam satu file ZIP terkompresi.
  • Standar Tanggal Indonesia: Otomatisasi konversi format tanggal ISO menjadi format resmi bahasa Indonesia (dd MMMM yyyy).
  • Sinkronisasi Database URL: Tautan Spreadsheet, Folder Drive, dan Web App terbaca langsung secara dinamis dari database.
